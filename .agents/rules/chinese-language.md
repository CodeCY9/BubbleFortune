# 语言规范 (Language Requirement)

1. **对话与回答**：在所有对话中，必须使用简体中文进行思考总结、解答和交流。
2. **文档创建与更新**：创建或修改任何 Markdown 文档（包括 `implementation_plan.md`、`walkthrough.md`、`README.md`、架构设计文档、注释说明等）时，必须统一使用简体中文编写内容。
3. **代码与标识符**：代码逻辑、变量名、函数名等保持标准的英文命名规范，但代码内的注释和说明文档需使用中文。
