## 存储与状态

新资产使用 art/<asset-id>/brief.md、concept/、source/、previews/、validation/；有实际产物时才建立对应子目录。公开模型目录仅保留当前 v009 双档箱子与 v007 的 26 箱舞台。22 个制作源/报告/预览文件已迁入 [chest-standard/legacy](../art/chest-standard/legacy/manifest.json)；17 个历史 GLB 已迁入各资产的 legacy/runtime，见 [路径、备份与哈希清单](validation/2026-09-10-runtime-archive.json)。现有 asset/ 文件保留在制作区。详见 [资产整理报告](validation/2026-09-10-asset-delivery.md)。

brief 保存规格、概念图/提示词、来源、当前阶段、最新检查源、最新有效源、导出版本、证据、问题和下一步。ASSETS 只索引；ROADMAP 只跟踪开发任务，避免三处复制明细。

阶段：规格 → 概念图 → 白模 → 模型/材质 → 动画 → 优化/导出 → 游戏验证 → 完成。
任务状态：待开始 / 进行中 / 待验证 / 阻塞 / 已完成。阶段与状态分别记录。Blender PASS 不等于 GLB 或整场景验收；静态图片不是 3D 模型。
