# 两人资本家对决：duel-26-v1

规则确认：2026-09-12。本文记录本轮已确认玩法；实现进度统一见 [ROADMAP](../ROADMAP.md)。游戏金额均为整数虚拟分数。

## 房间与身份

- 使用独立 `duel_26` 房间，固定两个席位。Colyseus 房间 ID 就是房间码；邀请链接为 `/duel?room=<房间码>`，打开链接仅预填，点击加入才占席。
- 房主可设置 4–64 个字符的私密房密码；服务端仅保存哈希，密码不进入快照、日志或历史响应；未设置密码时仍需通过房间码加入。密码房默认 `isPrivate=true`、`ranked=false`，仍保留历史但不计入正式赛季 Elo；创建时可由服务端显式锁定 `ranked`。
- 创建和加入要求 PostgreSQL 及游客身份可用。同一游客不能占两席；房间码不作为身份凭据，席位绑定游客 Cookie，重连令牌独立保存。
- 昵称最多 16 个字符，空昵称使用席位名称。双方在线且准备后由房主开始；等待阶段房主离开时转移房主并清除准备状态。开始后不能替换玩家。创建者可从 `classic` / `starry-neon` 白名单选择房间主题，并选择是否在公共实时快照中公开已完成报价历史；加入者以服务端快照同步，主题和历史开关不影响金额、轮次、随机映射或结算。关闭历史只减少公共投影，服务端仍保存完整审计。

## 两回合流程

- 第一回合由服务器随机分配挑战者与资本家，第二回合互换。每回合独立种子和箱子映射，复用 26 箱金额池及轮次 `6 / 5 / 4 / 3 / 2 / 1 / 1 / 1 / 1`。
- 挑战者选个人箱，按轮次开箱；共开 24 箱后直接保留或交换，不再报价。选个人箱限时 30 秒、每次开箱限时 20 秒，超时由服务器随机选择合法箱子；最终选择限时 30 秒，超时保留。
- 每个报价机会只允许资本家提交一次整数报价，提交后不可修改或撤回；25 秒未提交则跳过。挑战者收到报价后有 30 秒接受或拒绝，超时拒绝。
- 第一回合结束展示双方收益，双方继续或 30 秒到期后进入第二回合。服务器计时不等待客户端动画，也不因断线暂停。

## 合法报价

配置版本为 `duel-26-v1`。资本家每回合报价预算上限为 1,000,000。

设 `E` 为当前所有未开箱金额（含个人箱）的平均值，`r` 为本回合第几次报价机会（从 1 开始，跳过也计数）：

- 下限：`max(1, floor(E × (0.30 + 0.06 × (r−1))))`。
- 上限：`min(1,000,000, ceil(E × 1.20))`。
- 步长：1。随次数提高的是底价比例；大奖被开出后实际下限可以降低。

仅当前资本家的本人视图包含合法上下限和步长。客户端不接收平均值、系数、接受建议或隐藏金额映射。

## 收益与胜负

- 成交时：挑战者收益为成交报价，资本家收益为挑战者个人箱金额减报价，允许负收益。
- 未成交并走完最终选择时：挑战者收益为最终箱金额，资本家收益为 0。
- 完成两回合后分别累加收益，总分高者获胜，相同直接平局。
- 主动退出或断线超过 120 秒判弃权，对手获胜；处理超时时双方均已超过保留期则记双方弃权，无获胜者。
- 弃权保留已完成回合收益，未完成回合不生成虚构收益；当前总分不能覆盖弃权结果。等待阶段退出只释放席位。

## 公共状态、证明与战绩

- 挑战者独占选箱、开箱、处理报价及最终选择权限；资本家独占提交报价权限。命令序号与幂等记录按席位隔离，服务器校验阶段、版本、身份、截止时间及报价标识。
- 每回合开始发布随机承诺；整场结束后才公开所有已开始回合的种子与证明。第一回合结束不得公开整套映射。
- 双方各自延后揭晓金额栏、记录和后续操作，等待本端动画结束。刷新与重连恢复服务器已确认状态，不重播历史开箱。
- PostgreSQL 按对局 ID 去重保存双方归属、完整结果、报价与决策时间线。outbox 支持双人记录且兼容旧单人文件，数据库短暂故障不停止已开始对局裁决。
- `/api/duel/history` 和 `/api/duel/history/:matchId` 仅允许参与者读取；无权访问与不存在统一返回未找到，不返回对方游客凭据或数据库身份。参与者可通过 `POST /api/duel/history/:matchId/share` 创建公开摘要，读取路径为 `/api/share/duel/:shareId`，只包含排名、分数和终局原因。
- 进行中对局仍保存在内存，服务重启后的进行中恢复不在本轮范围。双人对局结束前（含回合间隔）禁止激活 PWA 更新。

## 本轮边界与证据

实现房间、邀请、准备、两回合对决、重连、结算、双方游客历史和参与者授权的公开分享摘要，复用舞台、箱子、动画与设置。排行榜、观战、聊天、信誉值、技能卡和新增美术资产均不在本轮范围；公开房间列表现已作为可选大厅发现能力接入，密码房默认不出现在列表中。

按用户要求，本轮不新增测试文件，不运行验证、测试、构建、Lint 或浏览器验收。双人业务代码已交付并在 ROADMAP 标记为待验证；已有单人测试记录不作为双人模式通过的证据。
