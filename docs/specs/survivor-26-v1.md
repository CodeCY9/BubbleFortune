# survivor-26-v1 箱王生存战

状态：基础业务闭环已交付，持久化、多人网络、设备和安全验收待完成。

- 2–6 名玩家分别选择个人箱。
- 仍在场玩家轮流打开中立箱。
- 每个中立箱揭晓后，活跃玩家分别收到私密报价。
- 接受报价后锁定分数并转为观战；拒绝后继续留场。
- 中立箱耗尽后，未成交玩家以个人箱金额结算。
- 排名按锁定报价或个人箱金额降序；弃权玩家保留已锁定分数并标记弃权。
- 公共视图不包含他人的报价、未开箱金额或游客凭据；主动玩家与观战者共用 26 箱 3D 舞台表现，金额仍只从服务端公开箱状态映射。房间允许最多 4 名只读观战者，观战视图的 seatId 为空且不能发送游戏命令。
- 创建者可设置 4–64 个字符的私密房密码；服务端只保留密码哈希，不进入公共房间摘要或快照。密码房默认 `isPrivate=true`、`ranked=false`，历史照常保存但不更新赛季生存战统计；创建时可由服务端显式锁定 `ranked`。
- 创建者可关闭观战或快捷表情，并从 `classic` / `starry-neon` 白名单选择视觉主题；房间开始后配置锁定，公共快照公布生效的 `allowEmotes` 和主题，服务器同时限制对应命令。主题不影响金额、轮次或排名。

当前限制：生存战使用轻量私密报价策略；终局会发布基于开局承诺的公平证明并支持快捷表情，游客历史、观战公共投影、重连令牌恢复、逐步回放和参与者授权的公开分享摘要已接入，权限隔离和赛季排名资格仍待验收。分享只公开终局排名与原因，不公开未开箱金额或报价。
